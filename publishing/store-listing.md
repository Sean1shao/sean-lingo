## 中文

名称：Sean Lingo

简短介绍：轻量划词翻译：单词释义、英美发音与句子翻译。免费使用，无需注册。

详细介绍：

Sean Lingo 帮你在阅读外文时，快速查懂一个词、读懂一句话。

在网页上选中文字，点击“译”即可查看结果；也可以使用右键菜单、Alt + L，或点击工具栏图标手动输入。

- 单词查询：英汉、汉英释义，英文音标与英美发音。
- 句子翻译：支持 Google 和有道，自动模式可在 Google 请求失败后尝试有道。
- 阅读浮窗：可移动、可编辑原文、可复制结果，按 Esc 即可关闭。
- 简洁设置：选择源语言、目标语言及翻译服务。
- 免费使用：无需账号，无需 API Key，没有付费解锁。

查询为在线服务：查询文字会发送至有道或 Google。Google 的可用性取决于网络；有道支持中英、中日、中韩、中法互译，日/韩/法语需明确选择源语言。每次最多 3000 字符。

Sean Lingo 不保存持久查询历史，不加入广告或行为分析。浏览器内部页面及扩展商店等受限页面无法使用划词浮窗，可使用工具栏输入查询。

这是一个基于 Lingo Link 开源代码独立维护的产品，与原项目及翻译服务提供方没有官方关联。开源许可及说明可在设置页查看。

反馈与支持：759112444@qq.com。

## English

Name: Sean Lingo

Short description: Lightweight word lookup and sentence translation. Pronunciation, selection popup, and no account required.

Full description:

Sean Lingo helps you understand a word or a sentence while reading the web.

Select text and click the translate button, use the context menu or Alt + L, or type directly in the toolbar popup.

- English–Chinese and Chinese–English dictionary entries.
- English phonetics and British/American pronunciation.
- Sentence translation through Google and Youdao, with automatic fallback when Google requests fail.
- A movable translation card with editable text and copyable results.
- Source/target language and provider settings.
- Free to use, without an account or API key. Voluntary sponsorship does not unlock features.

This extension uses online services. Query text is sent to Youdao or Google. Network availability affects Google access. Youdao supports Chinese paired with English, Japanese, Korean, or French; select the source language explicitly for Japanese, Korean, and French. Each query is limited to 3,000 characters.

No persistent query history, advertising, or behavioral analytics is built into the extension. Selection popups cannot run on browser-internal pages or extension-store pages; use the toolbar query instead.

Sean Lingo is independently maintained using open-source code from Lingo Link. It is not an official product of Lingo Link, Google, or Youdao. Licensing details are available in Settings.
